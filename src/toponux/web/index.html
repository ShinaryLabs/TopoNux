About network probes

  • These tools are active probes: ping, traceroute and TCP connections send packets.
  • They do not modify any address, route, firewall rule or system configuration.
  • An incomplete traceroute may simply mean that some routers do not answer probes.
  • A successful TCP test proves the connection is possible from this machine, not which rule allowed it.
  • A timeout alone does not prove a local firewall block.
