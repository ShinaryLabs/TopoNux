Reading the topology

Neighbours come from the local ARP/NDP cache, so they are recent peers rather than a full LAN inventory. Use Scan subnet to send one ping to every IPv4 host of the current local subnets and populate that cache. IPv6 and Docker entries are hidden by default. Local, broadcast and multicast routes are not drawn in this view. veth interfaces are grouped under their bridges. Use the dedicated tabs for the full inventory.

About network probes

  • These tools are active probes: ping, traceroute and TCP connections send packets.
  • They do not modify any address, route, firewall rule or system configuration.
  • An incomplete traceroute may simply mean that some routers do not answer probes.
  • A successful TCP test proves the connection is possible from this machine, not which rule allowed it.
  • A timeout alone does not prove a local firewall block.

How collection works

  • Each subsystem has its own collector. A failing collector stores its error in errors and returns a safe default, so one missing permission never hides the rest.
  • Commands run without a shell, with a fixed argument list and a 10-second timeout. No user input is ever passed to the collectors.
  • Data is collected only when you press Refresh, load the page, or run the subnet scan. There is no background polling. Nothing is stored unless you save a baseline: interfaces, routes, neighbours, listening sockets and connections (with process names) then stay in this browser's localStorage until you clear it.
  • Nothing leaves the machine: no analytics, no external API, no CDN. Cytoscape is vendored and served locally.
  • Collectors do not resolve hostnames and do not send packets. Only the active probes (ping, traceroute, TCP test, subnet scan) send traffic. Diagnostic probes are capped at 10 requests per minute; subnet scans are capped at 2 per minute and 512 hosts. The IPv6 inspector is purely local.

Permissions

  • ip and ss commands normally work as an unprivileged user. Process names for sockets owned by other users may be hidden without elevated privileges.
  • nft list ruleset and iptables-save may require root or CAP_NET_ADMIN. The firewall view reports the exact error instead of failing silently.
  • Toponux never runs sudo. If a command needs more privilege, run the server with the appropriate permissions yourself.
  • No command modifies interfaces, addresses, routes, rules, sockets or firewall state.

Known limits

  • The neighbour table only lists peers with recent traffic. Absence from the graph does not mean a host is unreachable.
  • STALE, DELAY and PROBE entries can be outdated.
  • Docker and virtual bridges hide their veth members; neighbours on those bridges are containers, not physical machines.
  • Firewall parsing is lossless for nftables JSON, best-effort for iptables text.
  • Socket data is a snapshot of the current network namespace. Process names may be incomplete without sufficient privileges.
  • Diagnostic results are observations at one moment, not proof of a permanent state.
